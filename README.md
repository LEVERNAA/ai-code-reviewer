# 🖥️ AI-Powered Code Reviewer

A sleek, custom-styled web application that provides instant, plain-language feedback and code critiques powered by Large Language Models.

![Python](https://img.shields.io/badge/Python-3.14-3776AB?style=flat&logo=python&logoColor=white)
![Streamlit](https://img.shields.io/badge/Streamlit-1.63-FF4B4B?style=flat&logo=streamlit&logoColor=white)
![Groq](https://img.shields.io/badge/Groq_API-gpt--oss--120b-F34B21?style=flat)

---

## 🌟 Key Features

* **Instant AI Feedback:** Get concise, 3-5 sentence reviews highlighting improvements, potential bugs, or best practices.
* **Multi-Language Support:** Select reviews tailored for Python, JavaScript, Java, C++, and more.
* **Custom Duotone UI:** Built with custom CSS featuring grid overlay motifs, glowing ambient accents, custom typography (*Sora* & *JetBrains Mono*), and responsive UI components.
* **Secure API Integration:** Environment secrets isolated securely via Streamlit secret management.

---

## 🛠️ Tech Stack

* **Language:** Python 3.14
* **Frontend Framework:** Streamlit
* **AI Engine:** Groq API (`openai/gpt-oss-120b`)
* **Deployment:** Streamlit Community Cloud
